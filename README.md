# Personal Portfolio – John Xedric A. Templanza

A personal portfolio website that introduces me, shows my skills and projects, and lists my education, achievements, and contact details.

**Live website:** https://xedric123.github.io/John_Xedric_A._Templanza/

## About the project
I am a BSIT 2nd year student at ICCT Colleges Cainta Main Campus. I built this site to present my work as an aspiring programmer.

## Technologies used
- **HTML** – page structure and sections
- **CSS** – layout, colors, responsive design, and dark/light themes
- **JavaScript** – interactive features
- **GitHub Pages** – hosting

## Main features
- Home, About, Skills, Projects, Education, Achievements, and Contact sections
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Dark and light mode toggle (remembers the choice)
- Typing effect on the home section
- Skill bars that animate when scrolled into view
- Project filter buttons
- Contact form with validation that opens the visitor's email app

## Files
- `index.html` – page content
- `style.css` – styling
- `script.js` – interactive features
- `todo.html` – To-Do List App project
- `guess.html` – Number Guessing Game project
- `profile.jpg` and `background.jpg` – images

## How to run
No installation needed. Download the files and open `index.html` in a browser, or visit the live website above.
