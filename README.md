# Personal Portfolio – John Xedric A. Templanza

A personal portfolio website that introduces me, shows my skills and projects, and lists my education and contact details.

**Live website:** https://xedric123.github.io/John_Xedric_A._Templanza/

## About the project

I am a BSIT 2nd year student at ICCT Colleges Cainta Main Campus. I built this site to present my work as an aspiring programmer.

## Technologies used

- **HTML** – page structure and sections
- **CSS** – layout, colors, responsive design, and dark/light themes
- **JavaScript** – mobile menu, theme toggle, project filter, typing effect, and contact form validation
- **GitHub Pages** – hosting the live website

## Main features

- Home section with my name, photo, and tagline
- About, Skills, Projects, Education, and Contact sections
- Navigation menu that links to every section
- Mobile-friendly menu and responsive layout
- Dark mode toggle
- Project filter (All, Web, School)
- Contact form with validation that opens the visitor's email app
- Working demos: To-Do List App and Number Guessing Game

## How to run the project

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No installation is needed.

## Project files

- `index.html` – main page
- `style.css` – styles
- `script.js` – interactive features
- `todo.html` and `guess.html` – project demos
- `avatar.jpg` and `background.jpg` – images
